# Moli Modules — paquete visual v1

Iconos originales 3D para accesos principales de Moli. Incluye `travel.png` para Viajes, `paperwork.png` para Trámites y `marketplace.png` para Market.

- PNG transparente de 512 × 512 px.
- Paleta naranja vivo, crema, blanco y carbón.
- Preparados para tarjetas, botones, estados vacíos y tutoriales.
- Sin logotipos, vehículos de marca ni sellos gubernamentales.
